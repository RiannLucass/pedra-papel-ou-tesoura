# 🪨 Pedra | 📜 Papel | ✂️ Tesoura

Um jogo clássico de **Pedra, Papel e Tesoura** desenvolvido com **HTML, CSS e JavaScript**, no qual o jogador enfrenta uma escolha aleatória feita pelo computador.

O projeto foi desenvolvido como uma forma de praticar **JavaScript, manipulação do DOM, funções, estruturas condicionais e geração de valores aleatórios**.

---

## 🎮 Sobre o Projeto

O jogador pode escolher entre três opções:

* 🪨 Pedra
* 📜 Papel
* ✂️ Tesoura

Após a escolha, o computador seleciona uma opção aleatoriamente e o sistema determina o resultado da rodada.

A pontuação do jogador e do computador é atualizada automaticamente durante a partida.

---

## 🚀 Funcionalidades

* 🪨 Escolha entre Pedra, Papel ou Tesoura
* 🤖 Jogada automática do computador
* 🎲 Escolha aleatória da jogada do Bot
* 🏆 Sistema de pontuação
* 🤝 Identificação de empates
* 📈 Atualização da pontuação em tempo real
* 💬 Exibição do resultado de cada rodada

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** — Estrutura da aplicação
* **CSS3** — Estilização e organização visual
* **JavaScript** — Lógica do jogo, interação com o usuário e manipulação do DOM

---

## 🧠 Lógica do Jogo

As regras utilizadas são:

| Jogador    | Bot        | Resultado     |
| ---------- | ---------- | ------------- |
| 🪨 Pedra   | ✂️ Tesoura | Jogador vence |
| 📜 Papel   | 🪨 Pedra   | Jogador vence |
| ✂️ Tesoura | 📜 Papel   | Jogador vence |
| 🪨 Pedra   | 🪨 Pedra   | Empate        |
| 📜 Papel   | 📜 Papel   | Empate        |
| ✂️ Tesoura | ✂️ Tesoura | Empate        |

Em qualquer outra combinação, o Bot vence a rodada.
